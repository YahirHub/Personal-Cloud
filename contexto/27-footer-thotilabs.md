# Footer global ThotiLabs

Se agregó un footer reutilizable al layout base para que las vistas web muestren `Powered by ThowiLabs`.

- Componente: `web/components/site_footer.html`.
- Integración: `web/layouts/base.html`.
- Estilos globales: `web/static/app.css`.
- El texto enlaza a `http://thowilabs.com/` y abre en una pestaña nueva con `noopener noreferrer`.
